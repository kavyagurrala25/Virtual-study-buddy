# 📚 Virtual Study Buddy

## 🌟 About the Project
Virtual Study Buddy is a student-focused learning website designed to help learners connect, share knowledge, and learn together. It encourages collaborative learning by bringing struggling learners and experienced candidates together in an interactive learning environment.

The project aims to make learning easier, more engaging, and accessible to students across different subjects.

## 🎯 Objectives
- Help students understand difficult subjects.
- Encourage knowledge sharing and collaborative learning.
- Promote interactive teaching and student participation.
- Support learners in improving their knowledge and confidence.
- Create a friendly environment for learning together.

## ✨ Features
- **Student Registration Form:** Collects student details such as name, year, branch, subjects, and email.
- **Login Navigation:** Provides a link to the login page.
- **Password Fields:** Includes password and password confirmation inputs.
- **Reset Option:** Allows users to reset the form fields.
- **Collaborative Learning:** Encourages students to share knowledge and learn from experienced candidates.
- **Interactive Teaching:** Promotes participation, discussion, and hands-on learning.

## 🛠️ Technologies Used
- HTML5
- Basic web page structure and form elements

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder on your computer.
3. Open `main.html` in your web browser.
4. Explore the student registration form and available navigation links.
